== Dashboard Next.js ==

O app roda em caminho ASCII (npm no Windows falha com "RELAÇÃO" no path):

cd "C:\Users\trind\Downloads\debitos-dashboard"
npm install
npm run dev

Abrir: http://localhost:3000

Na home: KPIs + gráficos (esfera, risco, top 10, tipos) e tabela com badges F/E/M.
No detalhe: abas Federal / Estadual / Municipal + gráficos da empresa + Baixar PDF.

Atualizar dados a partir dos PDFs:
cd "C:\Users\trind\Downloads\2. RELAÇÃO DE DEBITOS\scripts"
python build_dashboard_data.py

(ou, se houver script npm data no debitos-dashboard: npm run data)

== Extração Agenci@Net (OCR) ==

PDFs Agenci@Net costumam ser imagem/CID. Para extrair linhas estaduais/municipais:

1. Instale Tesseract OCR para Windows:
   https://github.com/UB-Mannheim/tesseract/wiki
   Marque o idioma Portuguese (por) na instalação.
2. Garanta que tesseract.exe esteja no PATH.
3. pip install -r scripts\requirements-debitos.txt

Sem Tesseract, o ECAC (federal) continua funcionando; Agenci@Net fica só com aviso.

== Upload Agenci@Net (servidor) ==

Após analisar PDFs, a confirmação usa o inbox temporário em:
  resultados/inbox_upload/MM-YYYY/{lote}/0_arquivo.pdf

Se aparecer "Arquivo temporário não encontrado no inbox", clique em
"Cancelar revisão" e analise de novo (não confirme horas depois).
Nomes do site (Agenci@Net, acento, espaços) passam a ser gravados no
inbox sem @; o Confirmar usa o caminho relativo do lote.

Badge DUPLICADO (já importado, mesmo hash): o PDF já está na pasta da
empresa. Marque a linha e clique em Confirmar — o painel é reindexado
(aba Estadual). Não precisa excluir o PDF antigo para reenviar o mesmo arquivo.

Deploy no servidor (GIT.TXT):
  git pull → npm run build → pm2 restart dashboard-debitos

PDFs Agenci@Net aceitos: Certidão Negativa GDF (~5 KB), Consulta com débitos,
DAR/Lançamento Administrativo. pymupdf é obrigatório (requirements-debitos.txt).
